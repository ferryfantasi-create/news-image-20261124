## How to run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`draw_image.py` is the local build script that paints `entry.png`
(1024x1024, Pillow). `main.py` is what gets graded: it only copies that
finished picture to `/output/entry.png`, using the standard library alone,
with no network access and the same output every time.
